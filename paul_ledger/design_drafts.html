Paul’s Book — three design drafts

Same real balances in each. Scroll inside a draft; on a narrow screen use the switcher.

Draft 1 — The Ledger

  • A real register: ruled rows, amounts in a fixed right column, double-rule under the carried balance.
  • Newsreader serif for names, JetBrains Mono for every figure. No cards, shadows or pills.
  • Oxblood debits, bookkeeper-green credits — colour only on the numbers.

Draft 2 — The Terminal

  • Trading-desk density: one monospace family, hierarchy by weight only, ticker strip for totals.
  • Column headers, hairline grid, bracketed tabs. Looks like a tool, not a product.
  • Muted greens/reds (not neon); amber reserved for “needs action”.

Draft 3 — The Broadsheet

  • One number carries the page: the net, set huge in narrow Archivo. Everything else is quiet.
  • Monochrome; the only colour is a single red for what Paul owes.
  • Strict left-aligned grid, heavy underline tabs, hairlines. Gallery-poster clarity.
